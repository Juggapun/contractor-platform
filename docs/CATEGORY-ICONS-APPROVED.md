ไฟล์มี alpha โปร่งใส ความละเอียดสูงสุด 512px บีบอัด WebP quality 90 ภาพต้นฉบับสร้างด้วย imagegen และเก็บในประวัติภาพของแชท การย่อและเข้ารหัสไม่เปลี่ยนเนื้อหาภาพ

แสดงเต็มภาพด้วย object-fit: contain ในพื้นที่เดิมของการ์ด จึงไม่ตัดหมวก เครื่องมือ หรือเท้า ชื่อหมวดเป็นข้อความและลิงก์จริง เส้นทางเดิมรวมถึงรับตรวจบ้าน→งานระบบคงเดิม ไม่มีการแก้ฐานข้อมูล

ไฟล์ชุดเก่าเก็บไว้ที่เดิมเพื่อย้อนกลับได้ เส้นทาง v2 ป้องกันเบราว์เซอร์ใช้ภาพเก่าจากแคช

ตรวจด้วยข้อมูลจำลองในเครื่องที่หน้าจอ 1440, 768, 375, 320px: ครบ 7 ภาพ โหลดสำเร็จ ลิงก์หมวดถูกต้อง ไม่ล้นแนวนอน ตรวจภาพเดสก์ท็อปและมือถือแล้ว ภาพ/ผลตรวจอยู่ใน docs/qa/category-icons/ ผ่าน TypeScript และ git diff --check
