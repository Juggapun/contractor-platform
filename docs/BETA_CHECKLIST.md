# รายการตรวจสอบก่อนเปิดทดสอบ (Beta Checklist)

เอกสารนี้เขียนไว้สำหรับเจ้าของเว็บไซต์/ผู้ดูแลระบบ (ไม่ต้องมีความรู้เรื่องโค้ด) ใช้ตรวจสอบด้วยตัวเองก่อนเปิดให้กลุ่มทดสอบจริงเข้ามาใช้งาน — ทำตามลำดับด้านล่างทีละข้อ แล้วติ๊กถูกเมื่อลองแล้วใช้งานได้ตามที่คาดไว้

## ก่อนเริ่ม: บัญชีทดสอบที่ต้องมี

ไม่ต้องใช้ข้อมูลลูกค้า/ผู้รับเหมาจริง — สร้างบัญชีทดสอบขึ้นมาใหม่ (อีเมลอะไรก็ได้ที่ยังไม่เคยใช้สมัคร) สำหรับแต่ละบทบาทด้านล่าง:

- **บัญชีลูกค้าทั่วไป 1 บัญชี** — สมัครผ่านหน้า "สมัครสมาชิก" ปกติ
- **บัญชีผู้รับเหมาทดสอบ 1 บัญชี** — สมัครผ่านหน้า "ลงทะเบียนผู้รับเหมา" (กรอกข้อมูลธุรกิจสมมติที่ระบุชัดว่าเป็นการทดสอบ เช่น ขึ้นต้นชื่อร้านด้วย "ทดสอบ" กันสับสนกับผู้รับเหมาจริง)
- **บัญชีผู้ดูแลระบบ (admin)** — ต้องให้ทีมพัฒนาช่วยตั้งค่าสิทธิ์ให้ก่อน (บัญชีธรรมดาไม่สามารถตั้งตัวเองเป็นแอดมินได้ ซึ่งเป็นความตั้งใจเพื่อความปลอดภัย)

เมื่อทดสอบเสร็จแล้ว **ลบบัญชี/ข้อมูลทดสอบเหล่านี้ออก** ก่อนเปิดใช้งานจริง อย่าปล่อยให้ผู้รับเหมา "ทดสอบ" ค้างอยู่ในระบบเพราะจะไปปนกับรายชื่อร้านจริง

## 1. เส้นทางลูกค้า (หาผู้รับเหมา)

- [ ] เข้าหน้าแรก เห็นหัวข้อ ปุ่มค้นหา และหมวดหมู่งานช่างชัดเจน
- [ ] ค้นหาโดยไม่ใส่ตัวกรองอะไรเลย ต้องเห็นรายชื่อผู้รับเหมา
- [ ] ลองกรองตามประเภทงาน / จังหวัด / คำค้นหา แล้วผลลัพธ์เปลี่ยนตาม
- [ ] ค้นหาคำที่ไม่มีผู้รับเหมาตรงเลย ต้องเห็นข้อความบอกว่า "ไม่พบ" ไม่ใช่หน้าว่างเปล่าหรือเออเรอร์
- [ ] คลิกเข้าไปดูโปรไฟล์ผู้รับเหมา 1 ราย เห็นชื่อ ที่อยู่ หมวดหมู่ ผลงาน (ถ้ามี) และรีวิว (ถ้ามี) ครบถ้วน
- [ ] ลองคลิกปุ่มโทร / LINE / Facebook / เว็บไซต์ (ถ้าผู้รับเหมารายนั้นมีข้อมูล) — ต้องเปิดช่องทางติดต่อถูกต้อง
- [ ] ลองเข้าโปรไฟล์ผู้รับเหมาที่ไม่มีอยู่จริง (พิมพ์ URL มั่ว ๆ) ต้องเห็นหน้า "ไม่พบผู้รับเหมา" ไม่ใช่หน้าเออเรอร์แปลก ๆ
- [ ] เข้าสู่ระบบด้วยบัญชีลูกค้าทดสอบ แล้วเขียนรีวิวผู้รับเหมา 1 ราย (ให้ดาว + เขียนความเห็น) — ต้องมีข้อความขอบคุณ และรีวิวต้องขึ้นในหน้าโปรไฟล์ทันที
- [ ] ลองเขียนรีวิวซ้ำผู้รับเหมารายเดิม — ต้องมีข้อความบอกว่ารีวิวไปแล้ว ไม่ใช่ฟอร์มว่างให้กรอกซ้ำ

## 2. เส้นทางผู้รับเหมา (สมัครเข้าร่วม)

- [ ] จากหน้าไหนก็ได้ในเว็บ ต้องหาทางไปหน้า "ลงทะเบียนผู้รับเหมา" ได้ง่าย (เมนูบนสุด หรือปุ่มท้ายหน้า)
- [ ] กรอกใบสมัครผู้รับเหมาทดสอบให้ครบ แล้วกดส่ง — ต้องเห็นข้อความยืนยันว่าส่งสำเร็จ และบอกชัดเจนว่า "รออนุมัติก่อนถึงจะขึ้นสาธารณะ"
- [ ] ค้นหาชื่อร้านที่เพิ่งสมัคร (ยังไม่อนุมัติ) ในหน้าค้นหา — **ต้องไม่ขึ้น** เพราะยังไม่ผ่านการอนุมัติ
- [ ] เข้าสู่ระบบด้วยบัญชีผู้รับเหมาที่เพิ่งสมัคร — ที่มุมบนขวาต้องเห็นป้ายสถานะ "รอตรวจสอบ"
- [ ] ให้บัญชีแอดมินเข้าไปอนุมัติใบสมัครนี้ (ดูข้อ 3 ด้านล่าง)
- [ ] หลังอนุมัติแล้ว ค้นหาชื่อร้านอีกครั้ง — ต้องขึ้นในผลการค้นหาแล้ว
- [ ] เข้าสู่ระบบด้วยบัญชีผู้รับเหมารายเดิมอีกครั้ง — ป้ายสถานะต้องเปลี่ยนเป็น "ผู้รับเหมา" พร้อมลิงก์ไปยังโปรไฟล์สาธารณะของตัวเอง

## 3. เส้นทางผู้ดูแลระบบ (อนุมัติผู้รับเหมา)

- [ ] เข้าสู่ระบบด้วยบัญชีแอดมิน แล้วไปที่เมนู "จัดการผู้รับเหมา" (อยู่ที่หัวเว็บไซต์เมื่อเข้าสู่ระบบเป็นแอดมิน)
- [ ] เห็นรายการใบสมัครที่รอตรวจสอบ พร้อมข้อมูลพื้นฐานให้ตัดสินใจได้ (ชื่อร้าน จังหวัด หมวดหมู่ วันที่สมัคร)
- [ ] คลิกเข้าไปดูรายละเอียดใบสมัคร 1 รายการ เห็นข้อมูลธุรกิจและช่องทางติดต่อครบ
- [ ] ลองกด "อนุมัติ" 1 รายการ — สถานะต้องเปลี่ยนเป็น "อนุมัติแล้ว" ทันที และหายจากคิวรออนุมัติ
- [ ] ลองกด "ปฏิเสธ" อีก 1 รายการ (ใส่เหตุผลสั้น ๆ) — สถานะต้องเปลี่ยนเป็น "ถูกปฏิเสธ" และหายจากคิวเช่นกัน
- [ ] ลองเข้าหน้าจัดการผู้รับเหมาด้วยบัญชีที่ไม่ใช่แอดมิน (เช่นบัญชีลูกค้าทดสอบ) — ต้องเห็นข้อความ "ไม่มีสิทธิ์เข้าถึง" ไม่ใช่ข้อมูลจริง
- [ ] ลองเข้าหน้าจัดการผู้รับเหมาโดยที่ยังไม่ได้เข้าสู่ระบบเลย — ต้องเห็นข้อความให้เข้าสู่ระบบก่อน ไม่ใช่ข้อมูลจริง

## 4. เข้าสู่ระบบ / ออกจากระบบ

- [ ] สมัครสมาชิกใหม่ 1 บัญชี แล้วเข้าสู่ระบบด้วยบัญชีนั้นได้ทันที
- [ ] เข้าสู่ระบบแล้ว หัวเว็บไซต์ต้องเปลี่ยนเป็นแสดงชื่อผู้ใช้ (ไม่ใช่ปุ่ม "เข้าสู่ระบบ/สมัครสมาชิก" เหมือนเดิม)
- [ ] กด "ออกจากระบบ" แล้วหัวเว็บไซต์ต้องกลับไปแสดงปุ่ม "เข้าสู่ระบบ/สมัครสมาชิก" ทันที
- [ ] หลังออกจากระบบแล้ว ลองรีเฟรชหน้าเว็บ — ต้องยังคงเป็นสถานะออกจากระบบ (ไม่ใช่กลับมาล็อกอินเอง)

## 5. ตรวจสอบบนมือถือ

ทำซ้ำข้อ 1–4 ด้านบนบนมือถือจริง (หรือย่อหน้าต่างเบราว์เซอร์ให้แคบเท่าจอมือถือ) โดยเน้น:

- [ ] เมนูแฮมเบอร์เกอร์ (ปุ่ม ☰ มุมบนขวา) กดเปิด/ปิดได้ และเห็นเมนูครบ
- [ ] เมื่อเข้าสู่ระบบด้วยบัญชีแอดมินบนมือถือ ต้องเห็นชื่อผู้ใช้และลิงก์ "จัดการผู้รับเหมา" ในเมนูมือถือด้วย (ไม่ใช่แค่บนคอมพิวเตอร์)
- [ ] ฟอร์มต่าง ๆ (ค้นหา, ลงทะเบียนผู้รับเหมา, เขียนรีวิว) กรอกและกดส่งได้สะดวกบนจอเล็ก ไม่มีปุ่ม/ช่องกรอกที่ล้นจอหรือกดยาก
- [ ] ตัวอักษรอ่านง่าย ไม่เล็กจนต้องซูม

## วิธีแจ้งปัญหาที่เจอ (ไม่ต้องรู้เรื่องโค้ด)

เจอจุดไหนที่ดูแปลก ใช้งานไม่ได้ หรือไม่เข้าใจว่าต้องทำอะไรต่อ ให้ทำดังนี้:

1. **ถ่ายภาพหน้าจอ** ตรงจุดที่มีปัญหา (มือถือกดปุ่ม Power + ปุ่มลดเสียงพร้อมกัน / คอมพิวเตอร์กด PrtSc หรือ Cmd+Shift+4)
2. เขียนสั้น ๆ ว่า **กำลังทำอะไรอยู่** และ **คาดว่าจะเกิดอะไร แต่จริง ๆ เกิดอะไรแทน** เช่น "กดปุ่มส่งรีวิวแล้วไม่มีอะไรเกิดขึ้นเลย" หรือ "ตัวหนังสือทับกันอ่านไม่ออกตรงหน้าโปรไฟล์บนมือถือ"
3. ส่งภาพหน้าจอ + คำอธิบายให้ทีมพัฒนา ไม่ต้องอธิบายเป็นศัพท์เทคนิค บอกแค่ว่า "เห็นอะไร" ก็พอ

## ข้อจำกัดที่ยอมรับได้สำหรับช่วงทดสอบ (ไม่ใช่จุดที่ต้องแก้ก่อนเปิด)

รายการนี้เป็นสิ่งที่ **รู้อยู่แล้วว่ายังไม่มี** แต่ไม่กระทบการทดสอบระบบหลัก — ไม่ต้องแจ้งซ้ำถ้าเจอ:

- ยังไม่มีระบบ "ลืมรหัสผ่าน" ในหน้าเข้าสู่ระบบ — หากบัญชีทดสอบลืมรหัสผ่าน ต้องให้ทีมพัฒนาช่วยรีเซ็ตให้ (ระบบยืนยันอีเมลจริงยังไม่ได้เปิดใช้งานในสภาพแวดล้อมทดสอบ)
- ยังไม่มีปุ่ม "เข้าสู่ระบบด้วย Facebook" (ตามแผนงานที่ยังไม่ถึงคิว)
- ผู้รับเหมาที่ถูกปฏิเสธจะเห็นแค่สถานะ "ถูกปฏิเสธ" ยังไม่มีหน้าที่บอกเหตุผลแบบละเอียด (ต้องติดต่อแอดมินเพื่อถามเหตุผลโดยตรง)
- หน้า "เกี่ยวกับเรา" / "ติดต่อเรา" / "นโยบายความเป็นส่วนตัว" ยังเป็น "เร็ว ๆ นี้" ยังไม่มีเนื้อหาจริง
- ยังไม่มีระบบแชท ระบบใบเสนอราคา หรือระบบชำระเงินใด ๆ ในเว็บไซต์ (ผู้ใช้ติดต่อกันเองผ่านโทร/LINE/Facebook ที่ผู้รับเหมากรอกไว้)
- จำนวนผู้รับเหมา/รีวิว/หมวดหมู่ที่เห็นตอนนี้เป็นข้อมูลจริงในระบบเท่านั้น (ไม่ใช่ตัวเลขทางการตลาด) — ถ้าดูน้อยเพราะยังอยู่ช่วงเริ่มต้นจริง ๆ ไม่ใช่บั๊ก

## จุดที่ควรถือเป็น "ต้องแก้ก่อนเปิดใช้งานจริง" (blocker)

ถ้าเจอข้อไหนต่อไปนี้ระหว่างทดสอบ ให้ถือว่าสำคัญกว่ารายการทั่วไป รีบแจ้งทันที:

- ข้อมูลของผู้รับเหมาที่ยังไม่อนุมัติ (รอตรวจสอบ/ถูกปฏิเสธ/ถูกระงับ) หลุดไปให้บุคคลทั่วไปเห็นได้ ไม่ว่าทางใดก็ตาม
- เข้าหน้าจัดการผู้รับเหมาได้โดยไม่ต้องเข้าสู่ระบบ หรือเข้าได้ด้วยบัญชีที่ไม่ใช่แอดมิน
- ใบสมัคร/รีวิว/การอนุมัติ กดส่งแล้วข้อมูลหายหรือไม่บันทึก
- เว็บไซต์ล่ม ขึ้นหน้าเออเรอร์สีขาวเปล่า ๆ หรือค้างไม่ตอบสนองในหน้าใดหน้าหนึ่งของ 4 เส้นทางหลักด้านบน
- ปุ่ม/ฟอร์มสำคัญ (ค้นหา, ส่งใบสมัคร, ส่งรีวิว, อนุมัติ/ปฏิเสธ, เข้าสู่ระบบ/ออกจากระบบ) ใช้งานไม่ได้เลยบนมือถือ
