# Home Page Master Design Reference

This document records the locked visual reference for the Home Page. The Project Owner's uploaded image is the authoritative visual source; this text is only a backup description because binary image attachment is not available through the current GitHub connector.

## Locked visual structure
- Full-page Thai contractor marketplace homepage for **หาช่าง**.
- White top navigation/header with logo at left; menu: หน้าแรก, ค้นหาช่าง, สำหรับช่าง, บทความ, เกี่ยวกับเรา; search icon; เข้าสู่ระบบ; yellow สมัครสมาชิก button.
- Large yellow hero with construction skyline/illustration, cartoon contractor wearing yellow hard hat and waving on the left, central dark navy brush-style headline block reading `ศูนย์รวม ผู้รับเหมาไทย`, supporting line `ค้นหาง่าย • ดูผลงานได้ • ติดต่อโดยตรง`, speech bubble on right.
- Hero search bar with จังหวัด, ประเภทงาน, and yellow ค้นหาช่าง button.
- White torn-paper transition and centered tagline `หาช่างดี สร้างบ้านดี สร้างอนาคตที่ดีกว่า`.
- Popular work-category icon row: รับสร้างบ้าน, ต่อเติม / รีโนเวท, งานไฟฟ้า, งานประปา, งานหลังคา, งานตกแต่งภายใน, งานรั้ว / ประตู, งานอื่นๆ.
- Dark navy statistics/trust strip with yellow icons and metrics shown in the reference.
- `ช่างแนะนำ` contractor-card section with five cards, photos, names, province, ratings, review counts, and category tags.
- `วิธีใช้งาน` four-step section.
- `ทำไมต้องใช้ หาช่าง ?` four benefit/trust cards plus contractor illustration on the right.
- Dark photographic contractor CTA banner with headline `เป็นช่างหรือผู้รับเหมาใช่ไหม ?`, yellow CTA button, and four contractor benefits.
- `เสียงจากผู้ใช้งานจริง` testimonial cards.
- `บทความ & เคล็ดลับ` three article cards.
- Dark navy footer with logo, menu/help columns, social icons, and brand message.

## Non-negotiable visual rules
- Do not redesign or invent a new visual direction.
- Preserve the reference's section order, proportions, composition, yellow/navy/white treatment, illustration style, typography hierarchy, spacing, card structure, header/footer, and overall visual density.
- Only change items explicitly required by the Home Page Issue.
- The uploaded Master Design image remains the source of truth for visual comparison; this markdown must not be treated as a replacement for seeing the image.
